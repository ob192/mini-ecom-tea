# Форматирование кода (логические секции)

Prettier (`.prettierrc`: табы, без `;`, двойные кавычки, `bracketSpacing: false`, один атрибут JSX на строку,
сортировка классов Tailwind) и ESLint (`eslint.config.mjs`) — обязательны: `pnpm format`, `pnpm lint`.
Этот файл — про **раскладку по смыслу** внутри объёмных React-единиц.

## Когда применять

- Компоненты страниц и виджетов с состоянием (`HomeInstructors`, `LayoutHeader`)
- Формы и feature-компоненты с данными и действиями (`SignupForm`)
- **Крупные** кастомные хуки

## Когда не применять

- Маленькие компоненты и хуки из 1–2 вызовов без handlers/computed
- `utils.ts`, `types.ts`, `constants.ts`, конфиги

## Порядок секций (сверху вниз)

Пустые секции **не пишем**.

| Секция            | Содержимое                                          |
| ----------------- | --------------------------------------------------- |
| _(без заголовка)_ | Инфраструктура: `usePathname`, `useId`, `useForm`   |
| **State**         | `useState`, `useRef`                                |
| **Computed**      | Производные значения                                |
| **Handlers**      | Колбэки и async-функции действий                    |
| **Effects**       | `useEffect`                                         |

```tsx
// State ---------------------------------------------------------
// Computed ------------------------------------------------------
// Handlers ------------------------------------------------------
// Effects -------------------------------------------------------
```

## Импорты

Всё под `src/` — **только абсолютные** пути через алиас `@/`. Относительные `./` и `../` запрещены (ESLint).

```tsx
// ❌
import {HomeFleetCard} from "./HomeFleetCard"

// ✅
import {HomeFleetCard} from "@/widgets/home/home-fleet/ui/HomeFleetCard"
```

Порядок групп (пустая строка между группами):

1. внешние пакеты (`react`, `next/*`, `react-icons/*`, `zod`)
2. `@/widgets` / `@/features` / `@/entities`
3. `@/shared` / `@/providers`

**Неиспользуемые импорты удалять** при каждой правке файла.

## Комментарии

Комментарий объясняет **почему** (решение владельца, ограничение браузера, контраст), а не что делает строка.
Документирующий комментарий компонента — над `export const`, о том, как блок выглядит и почему так.

## Прочее

- Полные имена переменных, без лишних сокращений
- `return` — после handlers и effects
