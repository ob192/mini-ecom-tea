# Тексты интерфейса

Сайт одноязычный: **все строки интерфейса — на украинском**, без i18n-библиотеки.

## Где живёт текст

| Текст                                                        | Где                                                   |
| ------------------------------------------------------------ | ----------------------------------------------------- |
| заголовки, лиды, подписи кнопок — то, что пишут один раз     | прямо в JSX компонента                                |
| то, что компонент отображает через `.map` (FAQ, машины, города) | `constants.ts` слайса                              |
| факты о школе (телефон, почта, адреса ссылок, рейтинг)       | `@/shared/constants/site`                             |
| ошибки формы и тексты ответа                                 | `features/signup/signup-form/constants.ts`            |

## Типографика

- Неразрывный пробел после коротких слов и между числом и единицей: `в&nbsp;Чернігові`, `5&nbsp;500&nbsp;₴`
  (в строке — `" "`).
- Апостроф — `ʼ` (U+02BC): `Імʼя`, `обовʼязково`.
- Кавычки — «ёлочки», тире — `—` с пробелами.
- Отзывы Google — дословно, как их оставили люди.

Новый текст сверять с `DESIGN.md` (раздел про тон) и соседними секциями.
